# Lounge: private rooms to talk and watch together

Static site (no server). Video, voice and screen sharing run peer to peer using WebRTC, with the free PeerJS cloud service used only to introduce browsers to each other.

## Deploy on GitHub Pages
1. Create a public repository on GitHub.
2. Upload index.html, style.css, app.js and README.md to the repository root.
3. Settings > Pages > Source: Deploy from a branch > main > /(root) > Save.
4. Open https://YOUR-USERNAME.github.io/REPO-NAME/ after a minute or two.

## Using it
- One person creates a room (name + password) and keeps their tab open.
- Others choose Join, enter the same room name and password.
- Click Share screen to share a tab or window (movie, YouTube, music). In Chrome, tick "Share tab audio" to include sound.
